# Experiments

Each experiment gets its own directory `EXP-NNN-...` with:

- `README.md` — hypothesis, falsification criterion, baselines, metrics, conclusion;
- `src/` — experiment-only code;
- `configs/` — reproducible configurations;
- `results/` — raw/derived metrics;
- `figures/` — generated figures;
- references to external implementation repositories pinned to commit SHA.
